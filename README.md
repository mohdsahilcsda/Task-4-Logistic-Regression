# Task 4 - Classification with Logistic Regression

## Objective

The objective of this task is to build a binary classification model using Logistic Regression.

## Tools Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## Dataset

Breast Cancer Wisconsin Dataset from Scikit-learn was used for this task.

## Steps Performed

1. Loaded the Breast Cancer dataset.
2. Checked the dataset structure and missing values.
3. Divided the data into training and testing sets.
4. Standardized the features using StandardScaler.
5. Built and trained a Logistic Regression model.
6. Made predictions on the test data.
7. Evaluated the model using:
   - Confusion Matrix
   - Precision
   - Recall
   - ROC-AUC
8. Created a ROC Curve.
9. Visualized the Sigmoid Function.
10. Tuned the classification threshold and observed changes in Precision and Recall.

## Evaluation

The Logistic Regression model was evaluated using Confusion Matrix, Precision, Recall, and ROC-AUC to understand its classification performance.

## Visualization

The following visualizations were created:

- Confusion Matrix
- ROC Curve
- Sigmoid Function

## Threshold Tuning

The classification threshold was changed from the default value of 0.5 to 0.4. The effect of this change on Precision and Recall was observed.

## Conclusion

Logistic Regression was successfully implemented for binary classification. The model was evaluated using different classification metrics, and the Sigmoid Function and threshold tuning were also explored.
